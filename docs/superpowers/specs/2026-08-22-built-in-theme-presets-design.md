# 内置主题预设设计

## 目标

将 MrRSS 现有的“亮色 / 暗色 / 跟随系统”切换升级为完整、可持久化的内置主题预设。读者可以在不编写 CSS 的前提下，为整个应用选择一致的阅读氛围；现有自定义 CSS 继续仅作用于文章内容。

## 已确认的产品决策

- 内置预设为 `Paper`、`Ink`、`Sepia`、`High Contrast`。
- `Auto` 是模式，不是预设：系统浅色时使用 Paper，系统深色时使用 Ink。
- 自定义 CSS 不扩展到应用外壳、设置页或对话框，以保持跨平台和无障碍行为可预测。
- 本次不提供用户编辑颜色 token 的界面。

## 方案选择

保留一个 `theme` 设置，取值扩展为 `auto`、`paper`、`ink`、`sepia`、`high-contrast`。不增加“颜色模式 + 预设”两个设置：两个值的组合会制造无效配置，例如 `Ink + Light`，也增加用户理解成本。

已有的 `light` 和 `dark` 值在读取时分别规范化为 `paper` 和 `ink`。规范化同时用于本地存储、应用启动和设置自动保存，因此旧用户不需要数据库迁移，也不会在启动时闪回旧色板。

## 主题模型

前端新增一个独立的主题工具模块，负责：

- 定义预设和合法偏好值；
- 将旧值或未知值规范化为合法偏好；
- 将 `auto` 按系统颜色模式解析为 Paper 或 Ink；
- 判断解析后的预设是否为深色，并为现有深色内容样式保留 `.dark-mode`；
- 将规范化偏好写入 `localStorage`，将解析后的预设写入 `data-theme-preset`。

主题颜色继续以语义 CSS 变量暴露。现有的背景、文本、边框、强调色、代码和标记变量在每个预设中完整覆盖；新增文章状态变量，使收藏、稍后读、成功、警告等常用状态不依赖固定 Tailwind 色值。Paper 是现有亮色体验的延续，Ink 是现有暗色体验的延续，Sepia 面向长时间阅读，High Contrast 使用黑白高对比和明确的强调色。

## 设置界面

“常规 > 应用”中的主题下拉框替换为主题选择器：

- 一项 Auto 选择，明确说明它在 Paper 与 Ink 间跟随系统；
- 四张固定尺寸、带颜色预览的预设按钮；
- 当前选择具有文字、选中图标和非颜色的边框/状态提示；
- 使用 `radiogroup`/`radio` 语义和本地化可访问名称；
- 在窄容器中自动换为单列或双列，按钮文字不会裁切。

选择后立即调用现有自动保存流程并更新根节点主题属性。主题选择器不依赖网络完成才给出视觉反馈；保存失败仍沿用当前设置保存错误处理。

## 启动与兼容性

`index.html` 的轻量启动脚本读取本地偏好，在样式加载前应用 `data-theme-preset`、页面背景和必要的 `.dark-mode` 类，以避免闪屏。它包含与 TypeScript 模块一致的旧值映射规则。

加载后，Pinia store 以后端设置为准并同步本地缓存。系统色彩变化只会在 `auto` 模式下触发重新解析；手动选择的预设不受系统变化影响。

## 范围

涉及：前端主题工具、Pinia 主题状态、启动脚本、全局 token、主题选择组件、通用设置页、中英文翻译、以及文章列表/工具栏中的主题状态色。

不涉及：后端数据库迁移、用户定义 token、全量替换所有业务语义色、移动设置页整体信息架构重构。
