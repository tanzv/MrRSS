# RSS 内容阅读模式设计

## 目标

为 RSS 内容提供一个低干扰、可键盘操作且无障碍友好的阅读模式。进入后，用户的注意力应落在文章正文，而不是订阅导航或文章列表。

## 已确认的交互决策

- 阅读模式只适用于 RSS 内容视图，不用于原网页 iframe 视图。
- 进入阅读模式时，隐藏左侧订阅栏和中间文章列表；退出后恢复原有布局与选择状态。
- RSS 正文的可滚动阅读区域获得键盘焦点，且不改变当前阅读位置。
- 阅读模式工具栏始终可见，但仅保留阅读所需的操作。
- 入口为文章工具栏中的明确按钮，并提供独立、可配置的快捷键；现有 `V` 快捷键继续只负责 RSS 内容与原网页的切换。

## 设计方案

### 状态与生命周期

`isReadingMode` 作为 Pinia 应用状态存在，仅在当前应用会话中保留，不写入本地持久化设置。这样用户可以在连续文章间保持沉浸式阅读，但重启应用后回到常规布局。

阅读模式只能在存在当前文章且 RSS 内容视图已启用时进入。关闭文章、切换到原网页视图或显式退出阅读模式时，状态会安全地关闭。通过文章导航进入下一篇文章时，模式保持开启，并在新文章的 RSS 内容就绪后重新聚焦正文。

### 布局与工具栏

应用根层保留侧栏和文章列表的组件实例，但在阅读模式下隐藏它们，以保留筛选、滚动位置和已选文章状态。文章详情区域扩展为全宽。

阅读工具栏保持常显，包含：

- 退出阅读模式；
- 切换 RSS 内容与原网页；
- 打开原文；
- 标记已读、收藏、稍后读；
- 显示阅读进度。

现有全局排版、主题和翻译设置继续生效；本次不新增重复的字体、主题或翻译设置入口。

### 焦点、键盘与无障碍

RSS 正文滚动容器将拥有 `tabindex="-1"`、`role="region"` 和本地化标签。进入模式并完成 Vue 渲染后，调用 `focus({ preventScroll: true })`；这使 Space、方向键与现有文章滚动逻辑立即作用于正文，同时不打断读者的位置。

阅读模式按钮带有本地化的名称和 `aria-pressed` 状态。模式切换通过简短的本地化状态提示告知辅助技术。

键盘规则如下：

- 新增独立、可配置的“切换阅读模式”快捷键，默认使用未冲突的 `m`。
- `V` 仍只切换 RSS/原网页；若该操作离开 RSS 内容，阅读模式同步退出。
- 第一次 `Escape` 退出阅读模式，第二次 `Escape` 才关闭文章；打开的查找、图片查看器和模态框保持其现有的优先级。
- Space、Shift+Space、上下方向键继续滚动 RSS 正文；输入框、可编辑内容和交互元素不受全局快捷键干扰。

### 错误与边界

- RSS 内容为空或加载失败时，不进入阅读模式，并保留现有错误/重试体验。
- 在移动端，阅读模式不强制改变当前的单栏导航模型；仅应用正文焦点与精简工具栏，避免破坏返回手势和现有布局。
- 若外部焦点操作（例如打开查找）发生，模式不自动夺回焦点。

## 实现边界

预计涉及：应用状态、`App.vue` 布局、文章详情与工具栏、文章详情 composable、全局快捷键、快捷键设置，以及中英文翻译。后端、数据库和 RSS 抓取流程不变。
