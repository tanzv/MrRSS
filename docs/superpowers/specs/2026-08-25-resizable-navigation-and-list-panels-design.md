# 订阅源与文章列表可调宽设计

## 背景与目标

MrRSS 的桌面工作流包含订阅源抽屉、文章列表和阅读区三个并列的工作面。当前
`useResizablePanels` 已维护一个未接入的侧栏宽度，而订阅源抽屉仍被固定为
`280px`（中等宽度窗口强制为 `240px`）；文章列表虽已有鼠标分隔线，却不保存
宽度，也不支持键盘操作。

本次让用户可以按阅读习惯调整订阅源抽屉与文章列表的宽度，而不增加侧栏的
视觉重量，也不改变移动端、自动收起、临时展开或阅读模式的状态逻辑。

## 交互模型

### 订阅源抽屉

- 仅在桌面宽度（`>= 768px`）且订阅源抽屉处于固定展开状态时，抽屉右边缘显示
  可调宽分隔条。
- 分隔条的命中区域为 6px；默认只保留克制的分隔提示，悬停、拖动或键盘聚焦时
  才使用当前主题的强调色。
- 拖动范围为 `240px` 至 `420px`。在较窄桌面窗口中，实际显示宽度还受可视区
  约束，但已保存的首选宽度不会被缩小覆盖。
- 双击恢复 `280px` 默认值。

### 文章列表

- 仅在桌面宽度、非卡片布局且不处于阅读模式时，文章列表右边缘显示同一交互
  模型的分隔条。
- 普通布局允许 `280px` 至 `600px`，紧凑布局允许 `300px` 至 `800px`，并维持
  当前布局模式已有的默认宽度（普通 `350px`、紧凑 `500px`）。
- 双击恢复当前布局模式的默认值；窗口或布局模式变化时，实际显示值在当前范围内
  夹取，但更宽布局的已保存首选值不丢失。

### 键盘与辅助功能

- 两条分隔条使用 `role="separator"`、垂直方向、可聚焦状态，以及当前/最小/最大
  宽度的 ARIA 属性和本地化标签。
- `ArrowLeft` / `ArrowRight` 以 16px 调整，配合 `Shift` 时以 48px 调整；`Home`、
  `End` 分别跳到最小、最大宽度。
- 拖动采用 Pointer Events 与指针捕获，拖动期间禁止文本选择并使用列调整光标；
  `pointerup`、`pointercancel` 和组件卸载都会恢复页面状态。

## 状态与持久化

`useResizablePanels` 继续作为唯一的宽度状态来源，但改为安全地读取、验证和写入
本地存储：

- `mrrss.sidebar-drawer-width`
- `mrrss.article-list-width`

无效、过期或无法读取的值使用当前默认值。持久化只发生在用户拖动、键盘调整或
双击复位后；后端设置 schema、数据库和同步 API 均不变。

订阅源抽屉的宽度与活动栏的固定 48px 宽度分离。自动收起只控制活动栏与边缘预览；
它不重置也不修改用户保存的订阅源抽屉宽度。非固定的临时订阅源抽屉没有调宽柄，
因此不会与指针离开后的自动收起相互影响。

## 组件与样式边界

- 增加一个小型复用分隔条组件，封装 Pointer Events、键盘交互、双击复位和 ARIA
  语义；它只发出数值更新，不保存业务状态。
- `App.vue` 持有 `useResizablePanels` 的状态：文章列表直接消费其宽度，订阅源宽度
  以 prop 和事件传给 `Sidebar`。
- `Sidebar` 只在固定订阅源抽屉可见时渲染订阅源分隔条，并将该宽度通过 CSS 自定义
  属性传递给 `FeedList`。
- `FeedList` 以该自定义属性取代硬编码的 `w-[280px]` 与 `@media (max-width: 1400px)`
  强制 `240px` 覆盖；移动端继续沿用现有 `44px` 活动栏和抽屉宽度上限。
- 分隔条不使用阴影、卡片或永久性的强强调色；布局拖动过程中不添加宽度过渡，避免
  内容滞后。现有的收起、边缘预览和抽屉开关过渡保持不变。

## 兼容性与非目标

- 不新增设置项、后端接口、数据库迁移或依赖。
- 不调整活动栏本身的 48px 桌面宽度、16px 自动收起边缘区或移动端 44px 触控目标。
- 不在移动端、临时展开订阅源抽屉、图片画廊或卡片模式中暴露可调宽行为。
- 不修改主题 token；分隔条只复用现有边框和强调色 token，因此与四套内置主题和
  自定义主题自然匹配。

## 验收与测试

1. `useResizablePanels` 单测覆盖本地存储恢复、边界夹取、布局模式范围、键盘/拖动
   更新后的持久化，以及无效存储值回退。
2. 分隔条组件测试覆盖 ARIA 语义、方向键、Shift 加速、Home/End、双击复位、指针
   捕获和取消清理。
3. `SidebarNavigation` 测试断言订阅源分隔条只在桌面固定状态出现，自动收起与边缘
   临时预览仍无调宽柄；文章列表测试断言其可调宽分隔条在既有可见条件下出现。
4. 在桌面和窄屏浏览器检查中验证两个分隔条不溢出、调整后内容持续可用、四套主题
   下聚焦态清晰；确认移动端、阅读模式和临时展开均不显示订阅源调宽柄。
